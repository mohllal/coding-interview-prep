# 3Sum Smaller Triplets

## Problem description

Given an array of `n` integers `nums` and an integer `target`, find the triplets `[nums[i], nums[j], nums[k]]` with `0 <= i < j < k < n` that satisfy the condition `nums[i] + nums[j] + nums[k] < target`.

## Hints

<details>
<summary>Hint 1</summary>

The counting version adds `right - left` in one step. If you must *list* the triplets rather than count them, you cannot take that shortcut.

</details>

<details>
<summary>Hint 2</summary>

Expand the shortcut into an inner loop over the valid range. That changes the output size, and so the space complexity, but not the time complexity.

</details>

## Solution

## Algorithm

Instead of counting, we record all valid triplets by iterating from `right` down to `left` when a valid sum is found.

## Complexity analysis

- Time complexity: $O(n^2)$ — the outer loop runs $n$ times and for each `i`, the two-pointer scan moves `left` and `right` a total of at most $n$ steps. The inner `for k` loop adds work proportional to the number of triplets recorded, which is already accounted for in the output size.
- Space complexity: $O(n^2)$ — the algorithm itself uses $O(1)$ extra space (two pointers, a loop index). The output list dominates: the outer loop has $n$ iterations, and each can produce up to $n$ triplets, so the result holds at most $n \times n = n^2$ triplets.

```python
class Solution:
    def three_sum_smaller(self, nums: List[int], target: int) -> List[List[int]]:
        nums.sort()
        n = len(nums)
        triplets = []

        for i in range(n - 2):
            left, right = i + 1, n - 1

            while left < right:
                current = nums[i] + nums[left] + nums[right]

                if current < target:
                    # All triplets (i, left, k) for k in [left+1, right]
                    # are also valid.
                    for k in range(right, left, -1):
                        triplets.append([nums[i], nums[left], nums[k]])

                    left += 1
                else:
                    right -= 1

        return triplets
```
