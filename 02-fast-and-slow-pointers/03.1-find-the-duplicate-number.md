# Find the Duplicate Number

## Problem description

Given an array of integers `nums` containing `n + 1` integers where each integer is in the range `[1, n]` inclusive. There is only one repeated number in `nums`, return this repeated number.

You must solve the problem without modifying the array `nums` and use only constant extra space.

## Examples

**Example 1:**

```plaintext
Input: [1,3,4,2,2]
Output: 2
```

**Example 2:**

```plaintext
Input: [3,1,3,4,2]
Output: 3
```

## Hints

<details>
<summary>Hint 1</summary>

Values lie in `1..n` and there are `n + 1` of them. Read `i -> nums[i]` as a link from one index to another — what shape does following those links produce?

</details>

<details>
<summary>Hint 2</summary>

A linked list with a cycle, whose entrance is the duplicated value. That reduces the problem to finding the start of a cycle.

</details>

## Solution

### Intuition

Think of the array as a linked list where each value points to the next index: `index → value → index`. Since values are in range `[1, n]` and we have `n + 1` elements, there must be a duplicate, which creates a cycle.

Each index `i` points to index `nums[i]`. Start at index 0 and follow the pointers:

```plaintext
nums = [1, 3, 4, 2, 2]

i         0   1   2   3   4
nums[i]   1   3   4   2   2

pointers: 0 → 1    1 → 3    2 → 4    3 → 2    4 → 2
                                     └ both point to 2 ┘
```

Two indices (3 and 4) point to the same index (2), and that is exactly what a duplicate value means. Following the pointers from 0 gives a linked list whose cycle starts at that shared target:

```plaintext
0 ──▶ 1 ──▶ 3 ──▶ [2] ──▶ 4
                   ▲      │
                   └──────┘

cycle start = 2 = the duplicate
```

Index 0 is a safe starting point: values are in `[1, n]`, so nothing points back to 0, and it always sits on the tail, never inside the cycle.

Then run [Start of Linked List Cycle](./03-start-of-linked-list-cycle.md) on this implicit list, with `next(i) = nums[i]`:

```plaintext
Phase 1 — find a meeting point inside the cycle

             slow   fast
start          0      0
iteration 1    1      3
iteration 2    3      4
iteration 3    2      4
iteration 4    4      4      ← meet on 4

Phase 2 — reset slow to 0, move both one step at a time

             slow   fast
start          0      4
step 1         1      2
step 2         3      4
step 3         2      2      ← meet on 2: the duplicate
```

**Example 2** — not every index is reachable from 0, and that's fine:

```plaintext
nums = [3, 1, 3, 4, 2]

i         0   1   2   3   4
nums[i]   3   1   3   4   2

0 ──▶ [3] ──▶ 4 ──▶ 2          1 ──┐
       ▲            │          ▲   │
       └────────────┘          └───┘

cycle start = 3 = the duplicate
```

Indices 0 and 2 both point to 3, so 3 is where the cycle begins. Index 1 points to itself, but it's never reached from 0, so it doesn't affect the answer.

### Algorithm

1. Use Floyd's algorithm treating `nums[i]` as the next pointer
2. Find meeting point inside cycle
3. Reset one pointer to start (index 0)
4. Move both one step → they meet at cycle start (the duplicate)

### Complexity analysis

- Time complexity: $O(n)$ - Linear traversal
- Space complexity: $O(1)$ - Only pointers used

```python
class Solution:
    def find_duplicate(self, nums: List[int]) -> int:
        # treat the array as a linked list: index i points to index nums[i]
        meeting_point = self.find_meeting_point(nums)
        return self.find_cycle_start(nums, meeting_point)

    def find_meeting_point(self, nums: List[int]) -> int:
        slow = fast = 0
        while True:
            slow = nums[slow]
            fast = nums[nums[fast]]
            if slow == fast:
                return slow

    def find_cycle_start(self, nums: List[int], meeting_point: int) -> int:
        finder = 0
        while finder != meeting_point:
            finder = nums[finder]
            meeting_point = nums[meeting_point]
        return finder  # the cycle's entrance is the duplicate value
```
