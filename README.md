# Grokking Coding Interview Patterns

This repository contains my solutions and notes for Design Gurus's [Grokking the Coding Interview: Patterns for Coding Questions](https://www.designgurus.io/course/grokking-the-coding-interview) course.

Each pattern directory holds a `README.md` explaining the pattern itself, a `PROBLEMS.md` listing its problems, and one file per problem with hints, an explanation, and a solution.
