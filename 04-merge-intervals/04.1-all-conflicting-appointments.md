# All Conflicting Appointments

## Problem description

Given a list of appointments, find all the conflicting appointments.

## Examples

**Example 1:**

```plaintext
Appointments: [[4,5], [2,3], [3,6], [5,7], [7,8]]
Output: [[[3,6], [4,5]], [[3,6], [5,7]]]
Explanation:
[3,6] and [4,5] conflict.
[3,6] and [5,7] conflict.
```

## Constraints

- `0 <= len(intervals) <= 10^4`
- `0 <= start < end <= 10^6`

## Solution

### Intuition

This is [Conflicting Appointments](./04-conflicting-appointments.md) with the early return removed: instead of returning `False` at the first clash, append the pair and keep going.

One caveat is worth stating plainly, because the adjacent-pair scan is not a complete solution to "find *all* conflicting pairs". It compares each appointment only against its immediate predecessor, so a long appointment overlapping three later ones contributes only the pairs that happen to be adjacent after sorting. It is enough to detect *whether* a conflict exists, which is what problem 04 asks, and it reports the neighbouring conflicts — but a genuinely exhaustive list of overlapping pairs needs each appointment compared against every still-open one, which is $O(n^2)$ in the worst case simply because there can be that many pairs.

```plaintext
[[4,5], [2,3], [3,6], [5,7], [7,8]]  sorted -> [[2,3], [3,6], [4,5], [5,7], [7,8]]

            1   2   3   4   5   6   7   8
[2,3]           ├───┤
[3,6]               ├───────────┤              3 < 3 false -> touching, no conflict
[4,5]                   ├───┤                  4 < 6 true  -> conflict [3,6] / [4,5]
[5,7]                       ├───────┤          5 < 5 false -> touching, no conflict
[7,8]                               ├───┤      7 < 7 false -> touching, no conflict

result: [[[3,6], [4,5]]]
```

Note that the scan misses `[3,6]` against `[5,7]`, which do overlap but are not adjacent after sorting — the limitation described above.

### Algorithm

1. Sort the appointments by start time
2. Walk adjacent pairs
3. If the current appointment starts strictly before the previous one ends, record the pair
4. Return the collected pairs

### Complexity analysis

- Time complexity: $O(n \log n)$ — the sort dominates the single scan.
- Space complexity: $O(n)$ — the conflict list holds at most `n - 1` pairs from an adjacent-pair scan.

```python
from typing import List


class Solution:
    def conflicting_appointments(self, intervals: List[List[int]]) -> List[List[List[int]]]:
        intervals.sort(key=lambda interval: interval[0])

        conflicts = []
        for i in range(1, len(intervals)):
            previous, current = intervals[i - 1], intervals[i]

            # touching appointments (a.end == b.start) do not conflict
            if current[0] < previous[1]:
                conflicts.append([previous, current])

        return conflicts
```
