# Minimum Platforms

## Problem description

Given a list of intervals representing the arrival and departure times of trains to a train station, find the minimum number of platforms required so that no train has to wait.

## Examples

**Example 1:**

```plaintext
Input: trains = [[2, 3], [2, 4], [3, 5]]
Output: 2
Explanation: Trains [2,3] and [2,4] arrive simultaneously, needing two platforms.
             [3,5] starts as [2,3] departs, so it reuses that platform.
```

**Example 2:**

```plaintext
Input: trains = [[1, 4], [4, 5], [5, 6]]
Output: 1
Explanation: Each train departs before the next arrives (using the ≤ boundary),
             so one platform handles all three in sequence.
```

**Example 3:**

```plaintext
Input: trains = [[1, 10], [2, 7], [3, 5]]
Output: 3
Explanation: All three trains are at the station simultaneously between t=3 and t=5.
```

## Constraints

- `0 <= len(trains) <= 10^4`
- `0 <= arrival < departure <= 10^6`

## Hints

<details>
<summary>Hint 1</summary>

The answer is the maximum number of trains at the station at any single moment. Before a new train arrives, which trains can have already departed — and which one do you check first?

</details>

<details>
<summary>Hint 2</summary>

For the two-pointer approach: you only care about *how many* trains are present, not which specific departure frees which arriving train's platform. That means you can sort arrivals and departures into two separate arrays and walk them with two pointers.

</details>

## Solution 1: min-heap of departure times

### Intuition

This is the same problem as Minimum Meeting Rooms with train terminology. The answer is the peak concurrency — the largest number of trains at the station at the same time.

Sort trains by arrival. Walk them left to right, carrying a min-heap of the departure times of trains currently on a platform. Before assigning a platform to the arriving train, pop every departure that is at or before the arrival time — those platforms are free again.

```plaintext
trains = [[2,3], [2,4], [3,5]]

process [2, 3]: heap empty → assign. heap=[3].           platforms in use = 1
process [2, 4]: heap=[3], 3 > 2 → none free.  heap=[3,4]. platforms in use = 2
process [3, 5]: heap=[3,4], 3 ≤ 3 → pop 3 (platform freed).
                heap=[4]. push 5. heap=[4,5].   platforms in use = 2

Peak = 2 platforms.
```

### Algorithm

1. Sort the trains by arrival time.
2. Keep a min-heap of departure times of trains currently on a platform.
3. For each train, pop every departure time ≤ its arrival — those platforms are freed.
4. Push its departure time and record the heap size as the current platform count.
5. Return the peak count.

### Complexity analysis

- Time complexity: $O(n \log n)$ — sorting dominates; each heap push/pop is $O(\log n)$ and each train is pushed and popped at most once.
- Space complexity: $O(n)$ — the heap holds at most one entry per train.

```python
import heapq
from typing import List


class Solution:
    def min_platforms(self, trains: List[List[int]]) -> int:
        trains.sort(key=lambda t: t[0])

        platforms = 0
        ongoing = []  # min-heap of departure times of trains currently at the station

        for arrival, departure in trains:
            # trains that have already departed free their platforms
            while ongoing and ongoing[0] <= arrival:
                heapq.heappop(ongoing)

            heapq.heappush(ongoing, departure)
            platforms = max(platforms, len(ongoing))

        return platforms
```

## Solution 2: two-pointer on sorted arrivals and departures

### Intuition

Because we only care about the *count* of trains at the station — not which specific departure frees which arrival's platform — we can separate the two timestamps entirely. Sort arrivals and departures into two independent arrays, then walk them with two pointers.

At each step, the next event is either the earliest unseen arrival or the earliest unseen departure — whichever comes first. An arrival adds a train (need one more platform); a departure removes one. The running count's peak is the answer.

```plaintext
trains = [[1,10], [2,7], [3,5]]

arrivals  (sorted): [1, 2, 3]
departures (sorted): [5, 7, 10]

i=0 j=0  arr[0]=1 < dep[0]=5  → new train arrives  count=1  i=1
i=1 j=0  arr[1]=2 < dep[0]=5  → new train arrives  count=2  i=2
i=2 j=0  arr[2]=3 < dep[0]=5  → new train arrives  count=3  i=3

i=3, done. Peak = 3 platforms.
```

Tie-breaking: when `arrival == departure`, the departing train has left and the platform is free, so process the departure first (`arrival < departure` triggers a new train, `arrival >= departure` triggers a free).

### Algorithm

1. Extract and sort arrivals. Extract and sort departures.
2. Walk with pointers `i` (next arrival) and `j` (next departure), advancing `i` when `arrivals[i] < departures[j]` and `j` otherwise.
3. Increment the count on an arrival, decrement on a departure.
4. Return the peak count.

### Complexity analysis

- Time complexity: $O(n \log n)$ — two sorts; the two-pointer scan is $O(n)$.
- Space complexity: $O(n)$ — the two auxiliary arrays.

```python
from typing import List


class Solution:
    def min_platforms(self, trains: List[List[int]]) -> int:
        arrivals = sorted(t[0] for t in trains)
        departures = sorted(t[1] for t in trains)

        count = 0
        platforms = 0
        i = j = 0

        while i < len(arrivals):
            if arrivals[i] < departures[j]:
                count += 1
                platforms = max(platforms, count)
                i += 1
            else:
                count -= 1
                j += 1

        return platforms
```

## Relationship to Minimum Meeting Rooms

Solution 1 is identical in structure to [Minimum Meeting Rooms](./05-minimum-meeting-rooms.md) — sort by start time, min-heap of end times, pop when the next interval begins. Only the variable names change.

Solution 2 is possible here because the two timestamps per train are treated as independent events. In the meeting rooms setting, you could also write a sweep-line solution (emit `(start, +1)` and `(end, -1)` events, sort, and sweep), which is a close cousin of this two-pointer approach.
